# Spool V1 execution ledger

This document connects implementation work to the accepted V1 plan. A task is
complete only when its implementation, tests, telemetry, and relevant release
gate are present.

## Status values

- `pending`
- `active`
- `blocked`
- `complete`
- `disabled`
- `preview`

## Initial ledger

| ID | Outcome | Status |
|---|---|---|
| DOM-01 | Typed identifiers and canonical job state machine | active |
| API-01 | Native `/v1` job and resource API | pending |
| API-02 | PrintNode printing compatibility API | pending |
| AGT-01 | Durable SQLite queue and event outbox | pending |
| AGT-02 | Signed enrolment and long-poll sync | pending |
| WIN-01 | Windows PDF and RAW executor | pending |
| CUP-01 | CUPS PDF and RAW executor | pending |

| DOC-01 | API, migration, self-host, and operations documentation | pending |

## Checkpoints

At each integration checkpoint, record the commit SHA, completed IDs, failed
gates, and explicitly disabled claims. New V1 scope is prohibited after the
native vertical slice begins.
